
## 🆘 Need Help?

### Quick Fixes

**Installation Issues?**
- Ensure Node.js 18+ is installed
- Delete `node_modules` and retry `npm install`

**Port Already in Use?**
- Stop other dev servers
- Or change port in `vite.config.ts`

**Build Errors?**
- Run `npm run build` to see all errors
- Check TypeScript configuration
