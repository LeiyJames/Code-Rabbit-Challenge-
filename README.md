# Dev Playground

A portfolio-grade Vue 3 web application for running interactive frontend experiments with advanced UX features.

## ✨ Key Features

### UX Enhancements
- 🔍 **Project search & filter** - Real-time filtering by name/description
- 🏷️ **Category tags** - Color-coded project categories
- 🎬 **Animated transitions** - Smooth page transitions
- ⌨️ **Keyboard shortcuts** - Esc, F, R, C for quick navigation

### Playground Features
- 💻 **Code preview** - View implementation snippets
- 🖥️ **Fullscreen mode** - Distraction-free project viewing
- 🔄 **Reset state** - Instantly restart projects
- 🛡️ **Error boundaries** - Graceful error handling

### Portfolio Features
- 💡 **"What I Learned"** - Educational insights per project
- 🏆 **Tech stack badges** - Visual technology indicators
- ⚡ **Performance optimized** - Lazy loading, code splitting
- 🎯 **SEO-friendly** - Meta tags, social sharing, Lighthouse-ready

## 🚀 Tech Stack

- **Vue 3** (Composition API)
- **TypeScript**
- **Tailwind CSS**
- **Vue Router**
- **Vite**

## 📦 Installation

```bash
npm install
```

## 🛠️ Development

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```

## 🌐 Deploy to Vercel

1. Install Vercel CLI: `npm i -g vercel`
2. Run: `vercel`
3. Follow the prompts

Or connect your GitHub repo to Vercel for automatic deployments.

## 📁 Project Structure

```
src/
├── assets/          # Static assets
├── components/      # Reusable UI components
├── projects/        # Individual project implementations
├── router/          # Vue Router configuration
├── types/           # TypeScript type definitions
├── views/           # Page components
├── App.vue          # Root component
└── main.ts          # Application entry point
```

## 🎮 Interactive Projects

1. **Calculator** - Full arithmetic operations
2. **Counter** - Increment/decrement with quick actions
3. **Lorem Ipsum Generator** - Customizable text generation
4. **Password Generator** - Secure passwords with strength meter

## 🎯 Usage

### Keyboard Shortcuts
- `Esc` - Go back / Exit fullscreen
- `F` - Toggle fullscreen mode
- `R` - Reset project state
- `C` - Toggle code preview

### Features Per Project
- View source code snippets
- Learn what each project teaches
- Run in fullscreen mode
- Reset to initial state
- Error-safe execution
