🔄 APPLICATION FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. USER VISITS APP
   └─→ Loads HomePage.vue
       └─→ Reads projects from projects.ts
           └─→ Renders ProjectCard for each project

2. USER CLICKS "RUN PROJECT"
   └─→ Navigates to /playground/:slug
       └─→ PlaygroundPage.vue loads
           └─→ Calls getProjectBySlug(slug)
               └─→ Dynamically renders project component

3. USER INTERACTS WITH PROJECT
   └─→ Project runs with its own state
       └─→ Fully self-contained logic
           └─→ Can use "Back" button to return

➕ HOW TO ADD A NEW PROJECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Create Component
────────────────────────
File: src/projects/MyProject.vue

<template>
  <div class="w-full max-w-2xl mx-auto p-6">
    <h2 class="text-2xl font-bold mb-6">My Project</h2>
    <!-- Your UI here -->
  </div>
</template>

<script setup lang="ts">
// Your logic here
</script>

Step 2: Register in projects.ts
────────────────────────────────
Add to the projects array:

{
  slug: 'my-project',
  name: 'My Project',
  description: 'Description here',
  techStack: ['Vue 3', 'TypeScript', 'Tailwind'],
  component: MyProject
}

Step 3: Done! ✅
────────────────
• Appears on homepage automatically
• Accessible at /playground/my-project
• No router changes needed
• No view changes needed
